1. **The CLAUDE.md FM-GEN-007 note is stale.** `ggen sync run` runs the
   full pipeline against the lsp-max pack on the installed 26.10.11 binary.
   It fails only at the receipt-log step: `[FM-CHAIN-003]` — the stale
   `.ggen-v2/relog...` log carries a pre-26.11-schema record (`generation`
   field). Repro: `ggen sync run` → exit 1 after writes, see 3 below.
2. **First sync run rewrote the three Overwrite-mode rules** (ocel-accumulator,
   file-types, declare-model): ocel_accumulator.rs, file_types.rs,
   declare_model.rs differ from the committed copies by rustfmt-style
   formatting only (hand-rustfmt'd committed copies vs template output) —
   the committed copies were hand-patched post-generation, a second source
   of truth. Direction of repair per GGM-SRC-002: regenerate and commit the
   template output, never re-hand-patch. On-disk copies are now
   template-canonical; a second run reports `unchanged: content identical`
   for all three (stability witnessed).
3. **The lib/main/backend "byte-identical" result was vacuous until
   forced.** Those three rules are `mode = "Create"`, which *skips* existing
   targets ("mode=create: target already exists"). The honest test stages a
   temporary manifest with the three rules flipped to `mode = "Overwrite"`
   (ggen.toml reverted immediately after; temp-manifest trick per
   run-ggen SKILL.md). Forced regeneration produced a ~2.9k-line drift on
   backend.rs alone: the templates emit a ~25-line stub server; the
   committed files carry 30+ modules and dozens of hand-written LSP
   handlers/analyzers/provider wiring that the ontology never modeled.
4. **Demotion chosen (not chain-closure).** Chain closure would require
   modeling 30+ modules of hand logic in the ontology+templates — the diff
   shows the files are hand-owned de facto. Honest demotion per contract:
   - `ggen.toml`: retired the `lib`, `main-rs`, `backend` rules.
   - Stripped the false "generated by ggen / CANDIDATE — receipt chain
     OPEN" banners from `src/lib.rs`, `src/main.rs`, `src/backend.rs`,
     replaced with hand-owned banners naming SA-9 and the demotion.
5. **Pre-existing gate gap (not session-introduced):** `cargo test` initially
   failed `compositor_front_door_end_to_end` on missing release binaries
   (`lsp-max-compositor`, then `claude-code-config-lsp` — `cargo build
   --release` in both repos fixed; both failures predate this lane and are
   environment gaps, not source regressions). With binaries built:
   **cargo test 591 passed / 0 failed** (CFL-1 baseline), clippy `-D
   warnings` clean.
