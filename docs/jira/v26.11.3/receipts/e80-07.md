## Design (the option that does not break callers)

W4 pins the legacy behavior (`read` accepts a body-corrupted window) as an
assertion, so flipping `read` itself would break the witness. Chosen:
**compat window** — keep `emit`/`read` byte-exact unchanged (documented
consumer-duty path), add a verified pair:

- `emit_verified(out, meta, body)` — identical framing to `emit`, plus a
  blake3 body digest (`crate::crates/cgap-arrow/src/blake3.rs::hash`)
  written into the **alignment-64 metadata padding** at
  `BODY_DIGEST_AT = PREFIX_SIZE + META_HEADER_SIZE`. Align-64 windows carry
  56 zero pad bytes there; legacy `read` never inspects metadata padding,
  so a verified window reads green through BOTH paths.
- `read_verified(buf, expected_schema, body_out)` — runs the full legacy
  `read` framing gauntlet first, then requires the stored digest ≠ absent
  (all-zero) and blake3(body) == stored, refusing typed.

## Typed error surface (additive, no external consumers broke — grepped:
zero `IpcError::` matches outside cgap-arrow)

- `IpcError::BodyDigestMissing` — verified read of a plain-`emit` window.
- `IpcError::BodyDigestMismatch { got: [u8; 32] }` — digest disagrees.
- `IpcError::BodyDigestNoRoom { got: u32 }` — align-8 verified emit/read
  (32 digest bytes need 32 metadata-padding bytes; align 8 has none).

## Tests (`tests/ipc_body_integrity_test.rs`, 5 courts, 5/5 green)

1. t1 clean verified window → legacy `read` green + `read_verified` green;
   digest slot populated.
2. t2 body-corrupted verified window → legacy `read` PASSES (documented
   consumer duty — the W4 law preserved) + `read_verified` refuses
   `BodyDigestMismatch` with the pristine-body digest as `got`.
3. t3 plain-`emit` window → legacy read green, `read_verified` →
   `BodyDigestMissing` typed.

5. t5 digest-slot tamper → `BodyDigestMismatch` (non-vacuity: the check
   really reads the stored slot, not an unconditional recompute).
