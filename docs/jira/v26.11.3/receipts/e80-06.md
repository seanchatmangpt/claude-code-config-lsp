## Diff

- NEW `crates/cgap-arrow/src/stream_writer.rs`: `pub struct StreamWriter<S>`
  over the crate-local `pub trait VectoredSink` (kernel-style writev,
  associated `Error`, `&mut T` forwarding impl). `emit(scratch, meta, body)`
  stamps the writer's monotonic `seq` over the caller's `meta.seq`, frames
  the IPC1 window via `ipc::emit` into a caller scratch buffer (alloc-free,
  the ipc.rs convention), then scatters prefix / metadata / body /
  pad+EOS segments with vectored writes, advancing past partial accepts
  until the whole window is accepted; a zero-byte accept is the typed
  `StreamError::ZeroProgress` refusal (the witness's `assert!(n > 0)`
  raised into the error surface). `StreamError<E>` = Framing(IpcError) |
  Sink(E) | ZeroProgress. Core-only: no std, no alloc — module is
  registered in lib.rs's embedded (no-OS) surface.
- NEW `crates/cgap-arrow/tests/stream_writer_type_test.rs`: 7 courts.
  T1 (type W1): live UDS, emit → writev → byte-exact IPC1 framing pins on
  the received bytes at 64-alignment; T1b: received window decodes via
  `ipc::read` to the exact slab body; T1c: 8-alignment scatter (new
  coverage; witness was 64-only); T2: writer seq stamped over caller's
  999 and advances monotonically; T3 (anti-vacuity): stalled sink (Ok(0))
  → typed ZeroProgress, seq not advanced; T4 (anti-vacuity): first-segment
  -only sink reassembles byte-identical to a raw `ipc::emit` reference
  window; T5: short scratch → Framing(Truncated) with exact `needed`,
  seq not advanced.
- REFACTORED `tests/stream_writev_witness.rs` (disclosed, per contract
  item 4): the hand-rolled emit + writev loop is replaced by
  `StreamWriter::with_seq(Uds adapter, seq).emit(...)`. W4's mutation now
  flips a body byte BEFORE emit (previously a window byte post-emit,
  pre-write) — same body-byte class, still never the shared tree; the
  mutated byte survives the socket byte-exact and the received body still
  differs from the sealed slab. Every W1/W2/W4 assert is unchanged.
- lib.rs: `pub mod stream_writer;` in the unconditional (embedded-safe,
  core-only) module list beside `ipc`.
